Most cm’s have this; puppet, chef, ansible, terraform. Bash/python scripts don’t have this. General pattern of get facts, for each resource get existing state, then change the state. Dry run doesn’t do the change step. Very very useful info in the delta. Others will complain that converging a dry run isn’t sufficient, but it is necessary. Caveats. You can make changes even in dry run mode, including reboots and erasing everything. Enforcing appropriate changes in dry run mode is currently manual. Idempotency affects this, but isn’t necessary.
